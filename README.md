# Avito Mini Parser

Репозиторий для тестового задания: мини-парсер объявлений Avito по артикулам.

Сейчас добавлен план выполнения: [PLAN.md](PLAN.md).

Планируемый подход:
- Python 3.10+;
- основной воспроизводимый режим через `samples/*.html`;
- опциональный live-режим без обхода CAPTCHA, авторизации и блокировок;
- результат в `result.csv`;
- тесты на парсинг, фильтрацию, дубли, top-5 и статусы ошибок.
