# Отчёт по выполнению

## Фактически затраченное время

Около 1.5–2 часов на планирование, реализацию, тестовые HTML, проверку и оформление репозитория.

## Возникшие сложности

- У Avito может меняться HTML-структура, поэтому парсер использует `data-marker` и простые fallback-селекторы.
- Прямые live-запросы могут быть недоступны из-за защиты Avito. В этом случае `--mode live` пишет строку `ошибка`, а `--mode live-first` может использовать сохранённые HTML как fallback.
- Масштабирование списка артикулов сделано через `--articles articles.csv`, без перестройки кода.

## Где использовался ИИ

ИИ помог составить план, выбрать минимальную структуру проекта, подготовить тест-кейсы, написать код парсера и README. Итоговая проверка выполнена запуском тестов и генерацией `result.csv`.
